## 🚀 Run Locally

You don't need any framework or build tools to run this project.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Zion_webpage.git
```

### 2. Open the project

```bash
cd Zion_webpage
```

### 3. Run the website

Simply open:

```text
index.html
```

in a modern web browser.

You can also use **VS Code + Live Server** for local development.

---

## 🌐 Deploy with GitHub Pages

This project can be hosted directly using GitHub Pages.

### Steps

1. Open the GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, select:

   * Source: **Deploy from a branch**
   * Branch: **main**
   * Folder: **/ (root)**
5. Click **Save**.
6. Wait for GitHub Pages to deploy the website.

Your website will then be available at:

```text
https://YOUR-USERNAME.github.io/Zion_webpage/
```
