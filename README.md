## 🚀 Run Locally

This project does not require any framework, package manager, or build tools.

### 1. Clone the repository

```bash
git clone https://github.com/vanasetti-charan/zion-power-ministries-website.git
```

### 2. Open the project

```bash
cd zion-power-ministries-website
```

### 3. Run the website

Simply open `index.html` in a modern web browser.

For development, you can also use **Visual Studio Code with Live Server**.

---

## 🌐 Deploy with GitHub Pages

This project is hosted using GitHub Pages.

### Deployment Steps

1. Open the GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, select:

   * **Source:** Deploy from a branch
   * **Branch:** `main`
   * **Folder:** `/ (root)`
5. Click **Save**.
6. Wait for GitHub Pages to complete the deployment.

### Live URL

```text
https://vanasetti-charan.github.io/zion-power-ministries-website/
```
